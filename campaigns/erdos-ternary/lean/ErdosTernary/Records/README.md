# Record modules (not in the default build)

A green `lake build` does NOT check these. Build and audit each one explicitly, e.g.
`lake build ErdosTernary.Records.CheckerKernelUpTo20` then
`python3 verify/lean_audit.py ErdosTernary.Records.CheckerKernelUpTo20 ErdosTernary.upToK_20 --expect UpTo:2*3^20`.

| module | theorem | tier | cost (one run) |
|---|---|---|---|
| UpTo30 (+ UpTo30/Shard0..7) | upTo_30 : UpTo (2*3^30) | B (native_decide, 8 shard modules, precompiled checker) | see proofs/g004-C02.md |
| UpTo28 | upTo_28 : UpTo (2*3^28) | B (native_decide, 8 shards) | ~8-11 min |
| CheckerKernelUpTo18 | upToK_18 : UpTo (2*3^18) | A (kernel) | ~3.5 min |
| CheckerKernelUpTo20 | upToK_20 : UpTo (2*3^20) | A (kernel) | ~15 min |

CheckerKernelUpTo18/20 were generated by tools/gen_kernel_upto.py (untrusted generator; Lean checks every piece)
and moved here unchanged from ErdosTernary/ (Critic, reports/gen_003/critic_C04.md).
