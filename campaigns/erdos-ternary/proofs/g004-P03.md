# g004-P03 乘子推广：对每个 3 ∤ λ，A_λ(X) ≤ (X+1)^{log_3 2}

级别说明见 CONSTRAINTS.md 第 3 条。Lean 源文件：`lean/ErdosTernary/CountingLambda.lean`
（命名空间 `ErdosTernary.CountingLambda`，import `ErdosTernary.Counting`，未改动 Counting.lean）。

记号：α := log_3 2；λ ∈ ℕ；A_λ(X) := #{0 ≤ n ≤ X : 2 ∉ Nat.digits 3 (λ·2^n)}；t_i(m) := ⌊m/3^i⌋ mod 3；
P := 2·3^k；T_{λ,k} := {r < P : t_i(λ2^r) ≠ 2 对所有 i ≤ k}；L_{λ,k}(Y) := #{r < Y : t_i(λ2^r) ≠ 2 对所有 i ≤ k}。
λ = 1 时这些就是 proofs/g002-L02.md 的 T_k、L_k、A。

## 命题

**定理（主结果）** LEAN-VERIFIED（`card_noTwo_mul_le_succ_rpow`，tier A）。
对所有 λ ∈ ℕ，3 ∤ λ，以及所有 X ∈ ℕ：A_λ(X) ≤ (X+1)^α。

Lean 陈述（直接用 Nat.digits 与 Finset.range，与 `Counting.card_noTwo_le_succ_rpow` 同形）：
```
theorem card_noTwo_mul_le_succ_rpow (l : ℕ) (hl : ¬ 3 ∣ l) (X : ℕ) :
    (((Finset.range (X + 1)).filter (fun n => 2 ∉ Nat.digits 3 (l * 2 ^ n))).card : ℝ) ≤
      ((X : ℝ) + 1) ^ Real.logb 3 2
```

**推论（λ = 1）** LEAN-VERIFIED（`card_noTwo_le_succ_rpow_of_lambda`）：取 l = 1，`one_mul` 后即 g002-L02 的
`card_noTwo_le_succ_rpow`，陈述逐字相同。

**定理（有限形式）** LEAN-VERIFIED（`card_noTwo_mul_le`）；数学上 KNOWN 的实质内容：Lagarias 2009 Thm 1.4
（对非零 3-adic λ，Ñ_λ(X) ≤ 2X^α，X ≥ 2，"using essentially the same proof" as Narkiewicz 1980；
出处据 specs/literature.md，本人未打开原文）。3 ∤ λ 且 X < 2·3^k ⇒ A_λ(X) ≤ 2^k。

与已知结果的关系：Lagarias Thm 1.4 的常数是 2（X ≥ 2）；这里对自然数 λ（3 ∤ λ）得到常数 1、对所有 X 成立。
λ = 1 时 X = 0、2 取等号（`CountingSharp.lean`），所以常数 1 对整个族不可改进；对单个 λ ≠ 1 是否紧，没有研究
（数值上 A_λ 很小，见下）。新颖性未经检索，不作判断。

## 证明（逐条对应 g002-L02 的引理 A–E，只改动用到 λ 的两处）

1. **引理 A、B**（trit 与数字、trit 的局部性）与 λ 无关，直接复用 `trit_ne_two_of_not_mem`、`trit_eq_of_mod_eq`。
2. **周期性**（`mul_two_pow_mod_period`，LEAN-VERIFIED）：λ2^n mod 3^{k+1} = λ·(2^n mod 3^{k+1}) mod 3^{k+1}，
   而 2^n mod 3^{k+1} 只依赖 n mod P（`two_pow_mod_period`）。不需要 3 ∤ λ。
3. **每个结点至多两个子结点**（`card_tree_succ_le`，LEAN-VERIFIED）：r ↦ r mod P 把 T_{λ,k+1} 映入 T_{λ,k}，纤维 ⊆
   {r_0, r_0+P, r_0+2P}。若三者都在纤维中，它们第 k+1 位都 ∈ {0,1}，必有 j < j' 第 k+1 位相等；低 k+1 位由周期性相等，
   于是 λ2^{r_0+jP} ≡ λ2^{r_0+jP}·2^{(j'−j)P} (mod 3^{k+2})。**这里用到 3 ∤ λ**：λ2^{r_0+jP} 与 3^{k+2} 互素
   （`coprime_three_pow`），可约去，得 2^{(j'−j)P} ≡ 1 (mod 3^{k+2})，与 `two_pow_period_not_modEq` 矛盾。
4. **根**（`card_tree_zero_le`，LEAN-VERIFIED）：T_{λ,0} ⊆ {0, 1}，条件分别是 λ mod 3 ≠ 2 与 2λ mod 3 ≠ 2。
   **这里用到 3 ∤ λ**：λ mod 3 ∈ {1, 2}，恰有一个满足，故 |T_{λ,0}| ≤ 1（实际 = 1）。λ = 1 时原证用的是 |T_0| = 1 的计算；
   这里只需 ≤ 1。归纳得 |T_{λ,k}| ≤ 2^k（`card_tree_le`）。
5. **引理 E**（`low_le_rpow`，LEAN-VERIFIED）：Y ≤ 2·3^k ⇒ L_{λ,k}(Y) ≤ Y^α。证明与 g002-L02 完全相同（对 k 归纳，
   三种情况：Y ≤ 2·3^k 用 L_{k+1} ≤ L_k；Y ≥ 3^{k+1} 用 2^{k+1} = (3^{k+1})^α；中间用一个整周期加长度 s < 3^k 的
   余段，L ≤ 2^k + s^α，再用 t ↦ t^α 的凹性 s^α + 3^{(k+1)α} ≤ Y^α + 3^{kα}，即 `concave_two_point`）。
   这一步只用到 |T_{λ,k}| ≤ 2^k 与周期性，和 λ 无关。
6. **主定理**：取 k = X，则 X+1 ≤ 2·3^X；n ≤ X 且 λ2^n 无数字 2 ⇒ n 被 L_{λ,X}(X+1) 计数（引理 A），再用引理 E。∎

## 注记

- **3 | λ 的情形** PROVED-HERE（未形式化）：λ = 3μ 时 Nat.digits 3 (3μ·2^n) = 0 :: Nat.digits 3 (μ2^n)（μ ≥ 1），
  所以 A_{3μ} = A_μ；对 3 的幂次归纳，主定理对一切 λ ≥ 1 成立。λ = 0 时 A_0(X) = X+1，不成立。
- 证明对 3-adic 单位 λ ∈ ℤ_3^× 同样有效（只用到 λ mod 3^{k+1} 与 λ 可逆）SKETCH；Lean 只陈述自然数 λ。
- 原假设说"只用到 2 生成 (ℤ/3^k)^×"。精确地说，用到的是：2 模 3^{k+1} 的阶整除 P = 2·3^k，且 2^P、2^{2P} ≢ 1
  (mod 3^{k+2})（即阶恰好是 2·3^{k+1} 而非 P），以及 λ 是模 3 的单位。

## 数值核对（脚本在 proofs/，自己写的 Python，结果为实际输出）

`python3 proofs/g004-P03_num.py 200 100000`：1 ≤ λ ≤ 200、3 ∤ λ 共 134 个 λ，0 ≤ X ≤ 100000，精确计数
（低 60 位过滤再对幸存者做完整三进制检查）。输出：
```
LMAX 200 XMAX 100000 lambdas 134
worst ratio A(X)/(X+1)^alpha: (1.0, (1, 0, 1))
failures: [] count 0
```
各 λ 的 A_λ(100000) ∈ {0, 1, 2, 3}（73 个为 0，46 个为 1，14 个为 2，λ = 1 为 3，命中 n = 0, 2, 8）。
这一检验很弱（计数太小），所以另检验证明实际界的量：

`python3 proofs/g004-P03_tree_num.py 200 7`：同样 134 个 λ，0 ≤ k ≤ 7，所有 0 < Y ≤ 2·3^k。输出：
```
LMAX 200 KMAX 7
tree size == 2^k in 1072 of 1072 (lam,k) pairs
worst ratio L(Y)/Y^alpha: (1.0, (1, 0, 1, 1))
failures: [] count 0
```
即 |T_{λ,k}| = 2^k 在所有 1072 对 (λ, k) 上取等号（等号未形式化，只形式化了上界），L_{λ,k}(Y) ≤ Y^α 无反例。
数值实验不算成果（第 11 条），只用于在形式化前排除反例。
