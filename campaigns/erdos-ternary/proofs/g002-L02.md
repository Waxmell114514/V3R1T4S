# g002-L02 计数上界：低位剩余类树给出 A(X) ≤ (X+1)^{log_3 2}

级别说明见 CONSTRAINTS.md 第 3 条。Lean 源文件：`lean/ErdosTernary/Counting.lean`（命名空间 `ErdosTernary.Counting`）。

记号：α := log_3 2 ≈ 0.63093；A(X) := #{0 ≤ n ≤ X : 2 ∉ Nat.digits 3 (2^n)}；第 i 位三进制数字（trit）
t_i(m) := ⌊m / 3^i⌋ mod 3。对 k ≥ 0 令 P := 2·3^k（2 模 3^{k+1} 的阶），
T_k := {r < P : t_i(2^r) ≠ 2 对所有 i ≤ k}，L_k(Y) := #{r < Y : t_i(2^r) ≠ 2 对所有 i ≤ k}。
（这里 k 比 g0-baseline 少 1：T_k 是 g0 记号中的"低 k+1 位"集合。）

## 命题

**引理 A（数字与 trit）** LEAN-VERIFIED（`trit_mem_digits`, `trit_ne_two_of_not_mem`）。
若 m/3^i ≠ 0，则 t_i(m) ∈ Nat.digits 3 m；因此 2 ∉ digits 3 m ⇒ 对所有 i，t_i(m) ≠ 2。
证明：对 i 归纳，用 digits 3 m = (m mod 3) :: digits 3 (m/3)（m > 0）。∎

**引理 B（局部性）** LEAN-VERIFIED（`trit_mod`）。i < k ⇒ t_i(a mod 3^k) = t_i(a)。
证明：3^k = 3^i·3^{k−i}，(a mod 3^i·3^{k−i})/3^i = (a/3^i) mod 3^{k−i}，再模 3（3 | 3^{k−i}）。∎

**引理 C（提升指数，手证）** LEAN-VERIFIED（`four_pow_three_pow`, `two_pow_period_mul`）。
4^{3^k} = 1 + 3^{k+1} t，3 ∤ t；进而对 j ∈ {1,2}，2^{jP} = 1 + 3^{k+1} u，3 ∤ u。
证明：k = 0：4 = 1 + 3。归纳：(1 + 3^{k+1}t)^3 = 1 + 3^{k+2}(t + 3(3^k t^2 + 3^{2k} t^3))，括号模 3 余 t。
j = 2：(1 + 3^{k+1}t)^2 = 1 + 3^{k+1}(2t + 3^{k+1}t^2)，括号模 3 余 2t ≢ 0。∎
推论（`two_pow_period_modEq`, `two_pow_period_not_modEq`, `two_pow_mod_period`）：
2^P ≡ 1 (mod 3^{k+1})，2^{jP} ≢ 1 (mod 3^{k+2})（j = 1, 2），2^n mod 3^{k+1} 只依赖 n mod P。

**引理 D（每个结点至多两个子结点，g0 引理 3 的上半）** LEAN-VERIFIED（`card_tree_succ_le`, `card_tree_le`）。
|T_{k+1}| ≤ 2|T_k|，从而 |T_k| ≤ 2^k。
证明：映射 r ↦ r mod P 把 T_{k+1} 映入 T_k（低 k+1 位只依赖 2^r mod 3^{k+1}，引理 B、C）。
r_0 ∈ T_k 的纤维 ⊆ {r_0, r_0+P, r_0+2P}。若三者都在纤维中，则三者第 k+1 位都 ∈ {0,1}，必有 j < j' 使第 k+1 位相等；
它们的低 k+1 位也相等（周期性），所以 2^{r_0+jP} ≡ 2^{r_0+j'P} (mod 3^{k+2})（`Nat.mod_pow_succ`），
约去与 3 互素的 2^{r_0+jP} 得 2^{(j'−j)P} ≡ 1 (mod 3^{k+2})，与引理 C 矛盾。故纤维大小 ≤ 2。∎
（等号 |T_k| = 2^k 是 g0 推论 4，PROVED-HERE；这里只形式化了上界，数值上对 k+1 = 1..13 核实了等号，见下。）

**定理 1（有限形式）** LEAN-VERIFIED（`card_noTwo_le`）；数学上 KNOWN：
Narkiewicz 1980（经 Lagarias 2009 Thm 1.4 / 式 (3.3) 转述）；Holdum–Klausen–Rasmussen, Integers 15 (2015) A43,
Lemma 2.12（出处据 Researcher g002-R03 的 specs/narkiewicz1980.md，本人未打开原文）。
X < 2·3^k ⇒ A(X) ≤ 2^k。
证明：n ≤ X < P 且 2^n 无数字 2 ⇒ n ∈ T_k（引理 A），再用引理 D。∎

**推论 2（实指数，常数 2^{1−α} ≈ 1.2915）** LEAN-VERIFIED（`card_noTwo_le_rpow`）；由定理 1 直接得到，视为 KNOWN 的推论。
X ≥ 2 ⇒ A(X) ≤ 2·(X/2)^α。
证明：j := ⌊log_3 ⌊X/2⌋⌋，则 2·3^j ≤ X < 2·3^{j+1}；定理 1 给 A(X) ≤ 2^{j+1} = 2·(3^j)^α ≤ 2(X/2)^α。∎

**定理 3（常数 1 的精确形式）** LEAN-VERIFIED（`card_noTwo_le_succ_rpow`）。新颖性：Researcher g002-R03 在文献中未找到，待独立判断。
对所有 X ≥ 0：A(X) ≤ (X+1)^α。X = 0（A = 1 = 1^α）与 X = 2（A = 2 = 3^α）取等号，所以常数 1 在此形式下最优。

关键引理 E（`low_le_rpow`）：对所有 k ≥ 0 和 0 ≤ Y ≤ 2·3^k，L_k(Y) ≤ Y^α。

证明（对 k 归纳）。k = 0：L_0(Y) ≤ L_0(2) = |T_0| = 1（T_0 = {0}），Y = 0 时 L_0 = 0，Y ≥ 1 时 1 ≤ Y^α。
k → k+1，Y ≤ 2·3^{k+1}，分三种情况：
1. Y ≤ 2·3^k：L_{k+1}(Y) ≤ L_k(Y) ≤ Y^α（条件更多；归纳假设）。
2. Y ≥ 3^{k+1}：L_{k+1}(Y) ≤ |T_{k+1}| ≤ 2^{k+1} = (3^{k+1})^α ≤ Y^α。
3. 2·3^k < Y < 3^{k+1}：写 Y = P + s，0 < s < 3^k。由周期性（`low_add_le`）
   L_{k+1}(Y) ≤ L_k(P + s) ≤ |T_k| + L_k(s) ≤ 2^k + s^α（归纳假设，s ≤ 2·3^k）。
   取 c = s ≤ a = Y, b = 3^k ≤ d = 3^{k+1}，满足 c ≤ a ≤ d、c ≤ b ≤ d、a + b = c + d（2·3^k + s + 3^k = s + 3^{k+1}）。
   x ↦ x^α 在 [0,∞) 上凹（Mathlib `Real.concaveOn_rpow`），两点优超（`concave_two_point`：把 a、b 写成 c、d 的凸组合，
   系数 λ = (d−a)/(d−c) 与 1−λ 互换，两次用凹性后相加）给出 s^α + (3^{k+1})^α ≤ Y^α + (3^k)^α，
   即 s^α + 2^{k+1} ≤ Y^α + 2^k，所以 2^k + s^α ≤ Y^α。∎
定理 3：取 k = X（X + 1 ≤ 2·3^X），A(X) ≤ L_X(X+1)（引理 A）≤ (X+1)^α。∎

注：定理 3 用到的不只是 |T_k| 的个数，还用到"一个周期加一段不足 3^k 的尾巴"的结构（情况 3），
这正是 Researcher 指出的"剩余类在周期中的位置"；但证明只需要 |T_k| ≤ 2^k 与周期性，不需要更精细的分布信息。

**评述** HEURISTIC/事实陈述：A(X) 真实值对 8 ≤ X < 3000 为 3（例外 n = 0, 2, 8，下方数值），而上界是 X^α 量级；
本条只改进常数，不触及猜想本身（g0 "已知障碍"仍然成立）。
