# g002-L01: residue-tree checker in Lean

Labels per CONSTRAINTS.md rule 3. Lean file: `lean/ErdosTernary/Checker.lean`. LEAN-VERIFIED here means: lake build

**Lemma 1 (`Checker.pow_period`)** LEAN-VERIFIED (tier A). `2^(2*3^i) % 3^(i+1) = 1`.
Proof: induction. If `2^(2*3^i) = 1 + 3^(i+1) q`, then cubing gives `1 + 3^(i+2) (q + 3^(i+1) q^2 + 3^(2i+1) q^3)`.

**Lemma 2 (`Checker.pow_class_mod`)** LEAN-VERIFIED (tier A). `2^(r + t*2*3^i) ≡ 2^r (mod 3^(i+1))`.

**Lemma 3 (`Checker.two_mem_digits_of`)** LEAN-VERIFIED (tier A). If `x / 3^i % 3 = 2` then `2 ∈ Nat.digits 3 x`.

**Checker.** Node `(i, r)` stands for the class `{r + t*2*3^i}`. It succeeds if `N < r`, or trit `i` of `2^r`
(computed as `Nat.powMod 2 r (3^(i+1)) / 3^i`) is 2, or `N < r + 2*3^i` and `r ≤ 8`; otherwise it succeeds when
its children `(i+1, r + j*2*3^i)`, j = 0, 1, 2, succeed. Depth is bounded by fuel `N + 64`; out of fuel = false.
`check N` checks the roots `(0,0)` and `(0,1)`. This simplifies verify/CERT.md (no E events, no exhaustiveness
test `3^k > 2^r`): a real exception `r > 8` with `r ≤ N` would make the recursion run out of fuel and return false.

**Theorem 4 (`Checker.check_sound : check N = true → UpTo N`)** LEAN-VERIFIED (tier A).
Proof: induction on fuel. For `t`, write `t = (t mod 3) + 3 (t / 3)` and use the child `j = t mod 3`.

**Theorem 5 (`upTo_small : UpTo (2*3^12)`)** LEAN-VERIFIED (tier A, `decide +kernel`).

**Theorem 6 (`upTo_vardi : UpTo (2*3^20)`)** LEAN-VERIFIED (tier B, `native_decide` on the closed term
`check (2*3^20)` only). It trusts the Lean compiler and runtime, including the native `Nat.powMod` (extern
`lean_nat_powmod`) and GMP. This is Vardi's bound again, now as a Lean theorem; it is not new.
