## 1. Source (KNOWN)
Lagarias, arXiv:math/0512006, Theorem 1.7, quoted in proofs/g002-P04.md §1. Its proof builds the set of λ whose
base-3 expansion is a concatenation of blocks of length n = ⌈log_3(N M_k)⌉, each block 0^n or (N)_3. The witness
N = 532261 for C(1, 2^2, 2^18) comes from g002-P04 and is LEAN-VERIFIED in `lean/ErdosTernary/E4.lean`
(`lagarias_witness_4_pow18`).

Block length (from a python run, this session): N, 4N, 2^18·N = 532261, 2129044, 139529027584 have 13, 14, 24
ternary digits, all in {0,1}; all three are < 3^24, and 2^18·N ≥ 3^23. So L = 24 is the least block length
that works for this witness.

## 2. Statements and paper proofs

**Lemma A (block concatenation; KNOWN-style, elementary).** If a < 3^L, 2 ∉ digits_3(a) and 2 ∉ digits_3(c),
then 2 ∉ digits_3(a + 3^L c). LEAN-VERIFIED: `noTwo_add_mul_pow`.
Proof: induction on L. L = 0 forces a = 0. For L+1, write n = a + 3P with P = 3^L c. If n = 0 the digit list is
empty. Otherwise digits_3(n) = (a mod 3) :: digits_3(⌊a/3⌋ + 3^L c). If a = 0 the head is 0; if a > 0 then
digits_3(a) = (a mod 3) :: digits_3(⌊a/3⌋), so a mod 3 ≠ 2 and 2 ∉ digits_3(⌊a/3⌋). Since ⌊a/3⌋ < 3^L, the
induction hypothesis finishes. ∎

**Lemma B (step).** If N, 4N, 2^18 N < 3^L have no ternary digit 2, a ∈ {0, N}, and c, 4c, 2^18 c have no
ternary digit 2, then the same holds for x = a + 3^L c. LEAN-VERIFIED: `good_step`.
Proof: M x = M a + 3^L (M c) for M ∈ {1, 4, 2^18}, and M a ∈ {0, M N} is < 3^L with no digit 2. Apply Lemma A. ∎
(This is the "no carries" point: each block product M·N fits in L digits.)

**Theorem C (general witness).** Let N > 0, 4N < 3^L, 2^18 N < 3^L, and suppose N, 4N, 2^18 N have no ternary
digit 2. Then for every J,
  2^J ≤ #{x < 3^(L·J) : x, 4x, 2^18 x have no ternary digit 2}.
LEAN-VERIFIED: `card_ge_of_witness`.
Proof: induction on J. Let G_J be the set on the right. J = 0: 0 ∈ G_0 = {0}. Step: the maps c ↦ 3^L c and
c ↦ N + 3^L c are injective, send G_J into G_{J+1} (Lemma B; and a + 3^L c < 3^L (c+1) ≤ 3^(L(J+1))), and
have disjoint images (residues 0 and N ≢ 0 mod 3^L, as 0 < N < 3^L). So |G_{J+1}| ≥ 2|G_J| ≥ 2^(J+1). ∎
Equivalently, the 2^J elements Σ_{j<J} ε_j N 3^(L j), ε ∈ {0,1}^J, are in G_J.

**Main theorem (PROVED here, LEAN-VERIFIED).** `ErdosTernary.E3Count.e3_count_4_pow18`:
```
theorem e3_count_4_pow18 (J : ℕ) :
    2 ^ J ≤ ((Finset.range (3 ^ (24 * J))).filter (fun x => 2 ∉ Nat.digits 3 x ∧
      2 ∉ Nat.digits 3 (4 * x) ∧ 2 ∉ Nat.digits 3 (2 ^ 18 * x))).card
```
Theorem C with N = 532261, L = 24, digit facts from `lagarias_witness_4_pow18` (4 is rewritten as 2^2).
It uses the frozen `Nat.digits` directly; it does not mention `Statement` or `UpTo`.

## 3. Not formalized
- "Therefore dim_H C(1, 2^2, 2^18) ≥ log_3 2 / 24" (the conclusion of Lagarias Thm 1.7) is **not** formalized.
  Mathlib has no Hausdorff-dimension theory for 3-adic Cantor sets; that step stays KNOWN (Lagarias). Theorem C is
  only its finite counting core, restricted to natural numbers (finite 3-adic expansions).
- The bound is far from sharp: g002-P04's automaton gives growth rate β with log_3 β ≈ 0.103480 for this
  component (numerical experiment, not LEAN-VERIFIED), whereas the theorem gives growth 2^(1/24) per digit.

## 4. Relevance
None to the Erdős conjecture itself (1 ∉ E(Z_3)). It concerns the E^(3) component C(1, 2^2, 2^18); it gives no
new bound on any dimension and does not improve dim_H E^(3) ≥ 0.228392 (Abram–Lagarias).
