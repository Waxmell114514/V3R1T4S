2. Large digits in prime bases

In this section we explore the base p representation of powers of an integer α, where p is
a prime not dividing α. We say that a digit n is “small” if n < p2 and “large” otherwise.
Further, p will always denote an odd prime, and α > 1 an integer with (α, p) = 1.
  The main goal of the section is to bound the following function in various ways.
Definition 2.1. Let p be an odd prime and a, n ∈ N. Fix α such that p ∤ α. Then set
                   Spn (a) = # {0 ≤ s < a | (αs )p contains < n large digits} .

Bounding the Spn is done by considering periodic properties of αk in base p as k varies.

2.1. Notation and definitions
Definition 2.2. Let p be a prime and n, k ∈ N. We write pk || n if pk | n and pk+1 ∤ n, i.e.
if k is the greatest exponent of p dividing n.
Definition 2.3. We define the following:
     • δ = {αk mod p | k ∈ Z}, i.e. δ is the set of residues generated by α modulo p.
     • θ = #{a ∈ δ | 0 ≤ a < p2 }, i.e. θ is the number of small residues in δ.
     • γ = ordp (α) = |δ|.
Definition 2.4. Let n ∈ N0 . We let Λn denote the set of sequences of the form
                                      ⟨σn , σn−1 , . . . , σ1 , σ0 ⟩,
where σ0 ∈ δ and 0 ≤ σi < p for 1 ≤ i ≤ n.
Definition 2.5. Let m ∈ N be represented in base p as m = i≥0 ai pi , where 0 ≤ aj < p.

        tmp /= 3
