# g0 理论基线：已知初等事实

级别说明见 CONSTRAINTS.md 第 3 条。

**引理 1（周期）** KNOWN。对 k ≥ 1，2 模 3^k 的乘法阶为 P_k = 2·3^(k-1)。
证明：2 是模 9 的原根（2 的幂模 9：2,4,8,7,5,1），由标准结论（模 p^2 的原根也是模 p^k 的原根，p 为奇素数）得出。

**引理 2（提升）** PROVED-HERE。对 k ≥ 1，2^(P_k) = 1 + c·3^k，其中 3 ∤ c。
证明：4 - 1 = 3，由提升指数引理 v_3(4^(3^(k-1)) - 1) = v_3(4 - 1) + v_3(3^(k-1)) = k。∎

**引理 3（恰 2 子节点）** PROVED-HERE。设 r 满足 2^r mod 3^k 的低 k 位三进制数字无 2。则在
r, r + P_k, r + 2P_k 中，2^n 的第 k 位（从 0 起）恰好取遍 0、1、2，所以恰有两个 n 的低 k+1 位无 2。
证明：2^(r + jP_k) = 2^r·(1 + c·3^k)^j ≡ 2^r + j·c·2^r·3^k (mod 3^(k+1))。
记 2^r ≡ a + t·3^k (mod 3^(k+1))，0 ≤ a < 3^k，则第 k 位为 t + j·c·(2^r mod 3) mod 3。
因为 3 ∤ c 且 3 ∤ 2^r，j ↦ 第 k 位是 Z/3 上的双射。∎

**推论 4** PROVED-HERE。设 S_k 为 0 ≤ r < P_k 中 2^r 低 k 位无 2 的 r 的个数，则 S_1 = 1，S_{k+1} = 2·S_k，S_k = 2^(k-1)。
因此 n mod P_k 的"坏"类所占比例为 2^(k-1)/(2·3^(k-1)) = (2/3)^(k-1)/2 → 0。
这只说明例外的 n 密度为零（KNOWN 型结论），不能推出例外有限，更不能推出猜想。

**启发式 5** HEURISTIC。若把 2^n 的约 0.63n 位三进制数字看成独立均匀，则 2^n 无 2 的"概率"约为 (2/3)^(0.63n)，
对 n 求和收敛，所以预期只有有限个例外。这不是证明，也是此问题难的原因：数字并不独立。

**已知障碍（待 Researcher 核实出处）** SPECULATION：完整证明似乎需要同时控制 2^n 的高位数字（阿基米德侧）和低位数字
（3-adic 侧）；树搜索只看低位，所以永远只能给出有限 N 的结论。
