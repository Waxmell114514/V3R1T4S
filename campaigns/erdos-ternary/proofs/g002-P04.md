# g002-P04: finite witnesses for E^(4)(Z_3) (exploratory, one mechanism)

Prediction recorded before running (orchestrator): likely 0 new theorems; if a witness exists, +1 tier-A finite statement.
Outcome: **no E^(4) witness in the searched range** (clean negative). There is one by-product: a tier-A finite

## 1. Criterion from the literature (KNOWN; quoted from the PDFs in specs/sources/)

Definitions (Lagarias, arXiv:math/0512006, (1.15)-(1.16)):
Σ_{3,2̄} := {λ ∈ Z_3 : the 3-adic expansion (λ)_3 omits the digit 2};
C(M_1, …, M_k) := {λ ∈ Z_3 : (M_j λ)_3 omits the digit 2 for 1 ≤ j ≤ k};
E^(k)(Z_3) = ⋃_{0≤m_1<…<m_k} C(2^{m_1}, …, 2^{m_k}).

**Lagarias, Theorem 1.7** (quoted from text extracted from arxiv-math0512006.pdf; the "Σ3,2̄ ∪ Z" is how the PDF text came out, and the proof writes "N ∈ Σ3,2̄ ∩ Z"):
> "Theorem 1.7. Let 1 ≤ M1 < M2 < · · · < Mk be positive integers. Suppose there is a positive integer N belonging
> to the 3-adic Cantor set Σ3,2̄ ∪ Z such that all the integers N Mi satisfy N Mi ∈ Σ3,2̄ ∩ Z, 1 ≤ j ≤ k. (1.19)
> Then dimH (C(M1 , M2 , ..., Mk )) ≥ log3 (2) / ⌈log3 (N Mk )⌉. (1.20)"
>
> "This result gives a possible approach to obtaining a nonzero lower bound for dimH (E (k) (Z3 )) for k = 4 or
> larger, if suitable Mi = 2^ni can be found that fulfill its hypotheses. However it can be shown that the sufficient
> condition of Theorem 1.7 is not necessary"

The proof builds Σ_C, the set of λ whose base-3 digits fall in blocks of length n = ⌈log_3(N M_k)⌉, each block
equal to 0^n or (N)_3. So the witness needed is an **actual positive integer** N whose products N·M_i have
*finite* expansions without the digit 2. A residue N mod 3^k for which N·M_i mod 3^k has k digits in {0,1}
is not enough: the carries above position k have to die out.

**Abram–Lagarias, Theorem 1.6** (arXiv:1308.3133v1; quoted): exact and necessary-and-sufficient.
> "(1) There is a terminating algorithm that takes as input any finite set of integers 1 ≤ M1 < . . . < Mn , and
> gives as output a labeled directed graph G = (G, L) with a marked starting vertex v0 , which is a presentation of
> a path set X = X(1, M1, M2 , · · · , Mn ) describing the 3-adic expansions of the elements of the space
> C(1, M1 , ..., Mn ) … This presentation is right-resolving and all vertices are reachable from the marked vertex.
> The graph G has at most ∏(1 + ⌊ ½ Mi ⌋) vertices.
> (2) The topological entropy β of the path set X is the Perron eigenvalue of the adjacency matrix A of the
> directed graph G. It is a real algebraic integer satisfying 1 ≤ β ≤ 2. Furthermore the Hausdorff dimension
> dimH (C(1, M1 , ..., Mn )) = log3 β."

The algorithm (their Thm 3.1 proof): a vertex is a carry N; digit a ∈ {0,1} is allowed iff a + N ≡ 0,1 (mod 3)
(their (3.2), here applied to N + M·a), and the next vertex is N' = ⌊(N + M a)/3⌋ (their (3.3)). For several
M_i, a vertex is the vector of carries.

Consequences used here (PROVED-HERE, elementary graph theory):
(a) dim_H > 0 ⇔ β > 1 ⇔ some strongly connected component of the reachable graph has more internal edges than
vertices (a strongly connected digraph has spectral radius 1 exactly when it is a single cycle).
(b) A Theorem 1.7 witness N exists ⇔ the zero-carry vertex has a cycle other than its 0-labelled self-loop (the
digits of N read along the cycle; the carry returns to 0, so N·M_i is finite with digits in {0,1}). In
particular (b) ⇒ (a).
(c) The residue count R_k = #{λ mod 3^k with digits in {0,1} : M_i λ mod 3^k has k digits in {0,1} ∀i}
is the number of length-k paths from v0. It grows like β^k up to polynomial factors, so it shows positive
dimension only through its growth rate. One residue on its own proves nothing, as expected.
Reduction (KNOWN, Lagarias Lemma 4.1): C(1, M) = {0} if M ≡ 2 (mod 3). Translating by 2^{-m_1}, which does not
change dimension, every component of E^(4) is C(1, 2^a, 2^b, 2^c) with 0 < a < b < c. It is {0} unless a, b, c are all even.

## 3. Findings

**E^(4) (the hypothesis): negative.** No C(1, 2^a, 2^b, 2^c) with even 0 < a < b < c ≤ 1000 (20,708,500 triples)
has positive Hausdorff dimension (exact criterion, Thm 1.6). So no Theorem 1.7 integer witness exists in this range.
By (c), for each such triple R_k grows subexponentially in k. Label: the computation itself is a numerical
experiment, not LEAN-VERIFIED. As a mathematical statement it is PROVED-HERE modulo the correctness of the code.
It says **nothing** about dim_H E^(4) > 0 or = 0. E^(4) is a countable union, and the range is finite.

**By-product (E^(3)): positive pairs beyond Table 5.2.** dim_H C(1, 2^a, 2^b) > 0 for
(a,b) = (2,8) 0.228391; (2,18) 0.103480; (2,24) 0.083861; (2,32) 0.074977; (2,38) 0.069649; (16,18) 0.087278;
(22,24) 0.067684; (24,26) 0.067080; (28,30) 0.067489. The other 180 pairs with b ≤ 40 have dimension 0, except
(36,38), which hit the state cap and is unresolved. All values come from the run output (pairs40.log).
Abram–Lagarias (2014) wrote: "Currently C(1, 22 , 28 ) is the only component of E (3) (Z3 ) known to have positive
Hausdorff dimension." Whether the others above have been reported since: **not checked**. None of them improves
the known bound dim_H E^(3) ≥ 0.228392.
Theorem 1.7 integer witnesses, from witness.py and independently re-checked by base-3 expansion in the same script:
- C(1,2^2,2^8): N = 1 (this is Lagarias' Σ_B construction).
- C(1,2^2,2^18): **N = 532261**. N, 4N and 2^18·N have 13, 14 and 24 ternary digits, all in {0,1}. Thm 1.7 then gives
  dim_H C(1,2^2,2^18) ≥ log_3 2 / 24 ≈ 0.0263. That is weaker than the automaton value 0.103480, and both are below 0.228.
- C(1,2^16,2^18): N = 282864854542 (25, 35 and 36 digits, all in {0,1}).
- C(1,2^2,2^24): positive dimension (0.083861) but **no** Thm-1.7 witness: the zero vertex sits in a trivial SCC.
  This is an instance of "the sufficient condition of Theorem 1.7 is not necessary".

## 4. Side observation (unresolved discrepancy with the literature)
Abram–Lagarias Table 5.2 lists dim_H C(1,2^8) = 0.287416. My automaton gives β = 1.4009249900 (numpy and power
iteration agree), so dim = 0.306871. The brute-force residue counts R_k for k = 6..14 are 12, 17, 25, 36, 51, 74, 107, 154, 218.
Successive ratios run about 1.41–1.44, which fits β ≈ 1.40 and not 3^0.287416 ≈ 1.37. The same paragraph of the paper
writes "2^8 = 256 = (10111)_3", but (10111)_3 = 94 and 256 = (100111)_3. I tested M = 94 (dim 0.324658) and it does
not explain the value either. Cause unknown. It does not affect any result above.

## 6. Relevance to the Erdős conjecture
Essentially none. The conjecture says 1 ∉ E(Z_3). Positive or zero dimension of E^(3) or E^(4) components bears on
Conjecture B (dim_H E(Z_3) = 0) only through the limit Γ = lim dim_H E^(k). Even a positive E^(4) component would not
touch Erdős's question, and a finite negative search cannot show that Γ = 0. HEURISTIC: the
dimensions of the positive E^(3) components we found shrink slowly (≈ 0.067–0.10) as the exponents grow. In the
range searched, every pair of them is incompatible: no triple survives. That fits the expectation that
dim E^(k) drops to 0 quickly in k. It is not evidence for the conjecture itself.
